ℹ️ About Smart Traffic AI

A Machine Learning based web application developed to predict traffic volume at city junctions using historical traffic data.

📖 Project Overview

Smart Traffic AI is an intelligent traffic prediction system that estimates the number of vehicles passing through a road junction based on historical traffic data. The application helps demonstrate how Machine Learning can support smarter traffic management and urban planning.

🎯 Project Objectives

  • Predict traffic volume using Machine Learning.
  • Reduce traffic congestion through data analysis.
  • Support Smart City planning.
  • Provide a user-friendly traffic prediction interface.

🛠 Technologies Used

🐍 Python
🌐 Flask
📊 Pandas
🤖 Scikit-Learn
📈 Matplotlib
📉 NumPy
🎨 HTML5
💻 CSS3

🤖 Machine Learning Model

Algorithm: Random Forest Regressor

The model was trained using historical traffic data with engineered date and time features to predict vehicle count.

📂 Dataset Information

  • Total Records : 48,120
  • Traffic Junctions : 4
  • Time Period : 2015 – 2017
  • Target Variable : Vehicles
